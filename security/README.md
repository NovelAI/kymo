# Build trust

Run `sh security/refresh-trust.sh --rustup` before toolchain or helper downloads. On Linux it updates the OS CA bundle and verifies the actual certificate fingerprints, then updates the calling user's Rustup. Debian/Ubuntu additionally deselect the affected roots; RPM-based runners require a patched distribution bundle. macOS runners must already provide a clean `/etc/ssl/cert.pem` or `SSL_CERT_FILE`; the check fails before downloads if that bundle is affected. An unprivileged caller uses sudo only for OS package and certificate-store changes; Rustup remains owned by the caller.

`install-dx.sh PREFIX` builds Dioxus CLI 0.7.9 from official commit `3e43ffa6cf1488d5388c888eb5f2494a006ae6de`. It verifies the source archive SHA256, applies `dx-0.7.9-tls.patch`, and installs with Cargo's `--locked` flag. The patch upgrades rustls-webpki 0.103.13 to 0.103.16 and webpki-roots 1.0.7 to 1.0.10. It also restores two missing dioxus-asset-resolver dev-dependency entries (`dioxus` and `serde_json`) so Cargo accepts the archived tree with `--locked`. This fixes the CLI's embedded trust store before it downloads build helpers; changing the application's Cargo lock or OS roots does not change a prebuilt CLI's trust store.

Run Actions only on patched runner images: JavaScript actions have their own bundled Node runtime. The Maturin action also bootstraps its manylinux container before `before-script-linux`, so that container must already have patched OS roots and Rustup. The hook verifies and refreshes trust before the application build; it cannot protect the action's earlier bootstrap. The release workflows use Maturin only to build wheels, not to publish over its independent HTTPS client.

The frontend Dockerfile, internal local-runtime workflow, and exported public release workflow use this installer. They retain CLI 0.7.9 and the application's Dioxus router fork. Source compilation costs more than downloading the old executable; the frontend CI jobs allow 60 minutes. If caching this build, include the official source revision, trust patch, Rust toolchain, and target in the cache key.
